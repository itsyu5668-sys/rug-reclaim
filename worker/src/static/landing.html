Frequently Asked

Clear answers, no BS.

Q

Is this safe?

The scan is read-only. The claim is a transaction you approve in Phantom, and you can read exactly what it does. The code is open source.

Q

Will it touch my coins?

No. It only closes accounts with zero token balance. Your holdings never move.

Q

Why 30%?

Because the alternative is that SOL sits there forever. First cleanup is free so you can verify that before paying anything.

Q

What happens to the fee?

It's in the transaction you approve. Nothing is taken silently, ever.
